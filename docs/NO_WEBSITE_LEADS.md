# Лиды без сайта (салоны и др.)

В фильтрах включи **«Тек сайты ЖОҚТАР»** / `require_no_website`.

Останутся только заведения **без website** в 2GIS — удобно для салонов красоты, барбершопов, студий, которым можно предложить сайт.

Рекомендуется вместе с:
- «Тек телефоны барлар» (`require_phone`) — чтобы был контакт
- дедуп ниш / франшиз

CLI:
```
parser-2gis-new -i "URL_2GIS_салоны" -o salons.xlsx -f xlsx --filters.require_no_website true --filters.require_phone true
```

Парсер ищет в 2GIS по рубрике (салон и т.д.) — сайт не нужен. Enricher дополнительно вытащит TG/VK/телефон из карточки.
